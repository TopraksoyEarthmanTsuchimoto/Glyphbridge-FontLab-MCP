# Refusal register

Every case a tool refuses, or that no tool supports yet, in one table: which tools refuse it, which handle it, and what would lift it. The rule that uses this file is in [AGENTS.md](../../AGENTS.md); the decision behind it is in [DECISIONS.md](../DECISIONS.md) (2026-11-24, refusals tracked in one register).

**How a row changes.** When a tool comes to handle a case, move the tool from "Refused by" to "Handled by" with its test numbers, and check the other tools in "Refused by" in the same proposal. A row that no tool refuses any more moves to a file in [archive/](../archive/README.md), with the date. The evidence stays in the file the last column links to; this table holds only the state.

`add_contours` (listener 0.207 / server 0.89) was run live in AD 1665–1680 ([LIVE-TESTS.md](../LIVE-TESTS.md)), and its several-shapes refusal in AD2 1684; its refusals again with server 0.90's wording in WX 1686 and 1692. `remove_contours` (listener 0.210 / server 0.91) refuses the same cases as `add_contours`, through the same table; its stale-count and stale-start refusals run live (RX 1735–1736 and 1745–1746, [LIVE-TESTS.md](../LIVE-TESTS.md)), a component beside the shape refused live as two shapes (RX4 1791); the others stub-tested only. Since listener 0.215 / server 0.94 the three edit tools handle several shapes and components moved by an offset (the user's design, [DECISIONS.md](../DECISIONS.md), 2026-11-25 and 2026-11-26), run live MS 1857–1895; their two rows moved to [archive/refusals-retired-rows.md](../archive/refusals-retired-rows.md) on 2026-11-26. Since 0.207 the edit tools' cases are also a table in the listener code, `_EDIT_ACCEPTS`; a stub test runs every tool in it against every case and fails when a tool departs from the table. A change here and a change there go together.
