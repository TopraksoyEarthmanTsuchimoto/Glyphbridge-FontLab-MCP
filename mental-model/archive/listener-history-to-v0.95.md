Run this from FontLab's Scripting panel to start a local HTTP listener
that exposes live FontLab session data to the Glyphbridge-FontLab-MCP
server running outside FontLab.

MANUAL START ONLY: run once per FontLab session. It keeps listening
until FontLab is closed.

Runs entirely on FontLab's main thread: a QTimer polls a non-blocking
socket every 25 ms, so every fontlab API call happens on the main
thread, which is the safe place for it.

Endpoints:
    GET  /health         -> {"status": "ok"}
    GET  /font/current   -> live info about the font open in FontLab
    GET  /font/glyphs    -> glyph names in the current font
    GET  /font/notdef    -> read-only .notdef check: status missing / empty / has_outline / unknown
    POST /font/notdef/warn -> re-checks, then (only if missing/empty and not yet warned for this font) shows an
                            information dialog in FontLab; body {"force": true} shows it again
    GET  /debug/font     -> everything the font object exposes (development)
    GET  /shutdown       -> stop the listener without closing FontLab
    POST /glyph/create   -> body {"name": "..."} creates one empty glyph.
                            Verified by re-reading font.glyphs after the
                            call; never reports success on trust alone.
                            When created, the reply also carries "unicode"
                            (int or null) and "unicode_status": "assigned"
                            (FontLab mapped the name by itself), "none" (no
                            codepoint; normal for non-standard names) or
                            "unreadable" (the read failed; NOT the same as none).
                            Optional body field "scan_unicode": N (the codepoint
                            the name states): if created and FontLab assigned
                            none, the reply also has "duplicate_check" (same
                            shape as for /glyph/unicode). If NOT created but a
                            glyph appeared under another name (FontLab strips
                            characters it does not accept), the reply lists them
                            in "created_under_other_names" (may contain "").
    POST /glyph/delete   -> body {"name": "..."} deletes one glyph.
                            Same verify-by-re-reading discipline as create.

                            (development only; not used by the MCP server).

                            draws closed straight-segment contours (1 to 20, each 3 to 500 points) as ONE shape into a glyph whose modern
                            layer is empty; creates the missing layer first when the glyph is empty.
