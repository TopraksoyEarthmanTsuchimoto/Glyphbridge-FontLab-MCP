# Archive

Snapshots and retired material. Nothing here is current: live facts are in the files listed in [MARKDOWN-MAP.md](../MARKDOWN-MAP.md).

## What belongs here

- **Snapshots** of a live file worth keeping, for example before a major rewrite.
- **Chat-era hand-offs**, kept as provenance. Only personal details are removed.
- **Superseded decisions**, and decisions no longer relevant to current work: [DECISIONS-ARCHIVE.md](DECISIONS-ARCHIVE.md).
- **Completed status items and DONE checklist rows**, when they are worth more than the topic file already records.

## Naming

`<live-name>-<descriptive suffix>.md`, for example `milestone-summary-v11.md` or `CURRENT-STATUS-2026-11-01.md`. Live filenames never change. Links to active information point at the live file, never at a snapshot.

## Moving something here

1. Copy, or move, the content into a new file named as above.
2. Remove it from the live file, leaving a link if readers still need it.
3. Update [MARKDOWN-MAP.md](../MARKDOWN-MAP.md) and check the relative links that pointed at the moved text.
